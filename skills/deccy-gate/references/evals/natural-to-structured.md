# natural-to-structured — gate

A constrained-notation dependent (requirement sentence, diagram) elaborates a prose
prerequisite.

## The check

This check is copied verbatim as the evaluation criterion; findings name elements at
check time:

1. Non-contradiction and non-re-decision: no element of the elaboration contradicts
   or re-decides the parent. Fail on any contradicting or re-decided element — name
   the element.

## Forbidden

Everything in natural-to-natural, plus: structured notation buys no license to demand
observables. A requirement sentence is still words; its gate is still non-violation.

## Why this much

Elaboration narrows a parent without becoming implementable. The gate keeps the
elaboration honest to the parent; whether it is met is decided further down, where the
child is code.
